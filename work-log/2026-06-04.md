## Key Learnings
- global hostapd reassigns ifnames on EVERY boot — unavoidable, accept it
- hostapd_cli CANNOT add VAPs to global hostapd (no ADD command)
- apply_vap.sh IS needed for runtime VAP creation (no other way without reboot)
- VLAN subinterfaces and bridges survive reboot via netifd
- VLAN MACs revert to eth1's MAC at boot — must be reapplied
